# Airbnb Australia Price Analysis
Exploring pricing patterns, occupancy trends and the different key features that drive and influence Airbnb performance across major Australia cities and states (Melbourne, Sydney, Brisbane, Tasmania and Western Australia)

This project aims to use exploratory data analysis (EDA),  data visualisations and predictive modeling to answer several questions such as: What is the optimal property size for a return on investment? What is the sweet spot for an Airbnb listing - how many bathrooms or bedrooms? What are the key differences between Airbnb listings across different states in Australia?

Data: Inside Airbnb (June, 2025) - https://insideairbnb.com/get-the-data/
